Project Brief

Question

How can a user quickly generate a study area boundary map when they either have their own boundary file or need to obtain an available boundary for their study area?

## Data I Need

1. User-provided boundary
- Shapefile
- GeoJSON
- KML/KMZ

2. Available administrative boundaries (divagis.com)
- Country boundary 
- State boundary
- Local Government Area (LGA) boundary
- Other available administrative boundaries

3. Base map (osm)
- OpenStreetMap or another suitable web basemap

Expected Output

A study area boundary map showing the selected study area with basic map elements such as:
- Title
- Legend
- North arrow
- Scale bar
- Boundary
